# Statistical Analysis Suite - Database Integration Guide

## 📋 Overview

This document provides complete instructions for integrating SQLite database functionality into your Statistical Analysis Suite application. The database system stores analysis history, enables searching, and provides export capabilities.

## 🚀 Quick Start

### 1. Install Database Module

Copy `database.py` to your `modules/` folder:

```bash
cp database.py main/modules/
```

### 2. Replace Main Menu

Replace your existing `main.py` with the new database-integrated version:

```bash
cp main.py main/
```

### 3. Run the Application

```bash
cd main/
python main.py
```

The database will be automatically initialized on first run.

## 🔗 Integrating Analysis Modules

### Step-by-Step Integration

Each analysis module needs three simple modifications:

#### 1. Add Database Attribute in `__init__`

```python
class YourAnalyzer(ctk.CTk):
    def __init__(self):
        super().__init__()
        
        # ... existing initialization ...
        
        # ADD THIS LINE:
        self.db_save_function = None  # Set by main.py if database available
```

#### 2. Add Save Method

```python
def save_to_database(self):
    """Save analysis results to database"""
    if self.db_save_function is None or self.results is None:
        return
    
    try:
        # Prepare data
        input_data = {
            'parameter1': self.param1,
            'parameter2': self.param2,
            'n': self.n
        }
        
        results = {
            'statistic': float(self.results['statistic']),
            'p_value': float(self.results['p_value']),
            'conclusion': self.results['conclusion']
        }
        
        interpretation = "Your interpretation text here"
        
        metadata = {
            'title': self.title_entry.get().strip(),
            'date': datetime.now().isoformat()
        }
        
        # Call save function
        self.db_save_function(
            analysis_type="Your Analysis Name",
            input_data=input_data,
            result=results,
            interpretation=interpretation,
            metadata=metadata
        )
        
    except Exception as e:
        print(f"⚠️ Warning: Could not save to database: {e}")
```

#### 3. Call Save After Analysis

```python
def run_analysis(self):
    """Perform your statistical analysis"""
    try:
        # ... perform analysis ...
        
        self.results = {
            'statistic': calculated_stat,
            'p_value': calculated_p,
            'conclusion': conclusion_text
        }
        
        self.display_results()
        
        # ADD THIS LINE:
        self.save_to_database()
        
    except Exception as e:
        messagebox.showerror("Error", str(e))
```

## 📊 Database Schema

### `analysis_history` Table

| Column          | Type      | Description                              |
|-----------------|-----------|------------------------------------------|
| `id`            | INTEGER   | Primary key (auto-increment)             |
| `analysis_type` | TEXT      | Type of analysis (e.g., "ANOVA")         |
| `input_data`    | TEXT      | JSON string of input parameters          |
| `result`        | TEXT      | JSON string of statistical results       |
| `interpretation`| TEXT      | Human-readable conclusion                |
| `date_created`  | TIMESTAMP | Automatic timestamp (default: now)       |
| `metadata`      | TEXT      | JSON string of additional info (optional)|

### Indexes

- `idx_analysis_type`: Fast filtering by analysis type
- `idx_date_created`: Fast sorting by date (descending)

## 🔒 Security Features

### SQL Injection Prevention

All database queries use parameterized statements:

```python
# SAFE - Parameterized query
cursor.execute(
    "SELECT * FROM analysis_history WHERE id = ?",
    (record_id,)
)

# UNSAFE - String concatenation (NOT USED)
# cursor.execute(f"SELECT * FROM analysis_history WHERE id = {record_id}")
```

### Data Sanitization

- JSON serialization for complex objects
- Type conversion for numpy arrays
- Error handling for malformed data

## 🐛 Troubleshooting

### Issue: "Database module not found"

**Solution:**
```bash
# Ensure database.py is in modules folder
ls modules/database.py

# Check __init__.py exists
touch modules/__init__.py
```

### Issue: "Table doesn't exist"

**Solution:**
```python
# Reinitialize database
database.create_tables("stats_app.db")
```

### Issue: "JSON decode error"

**Solution:** The module is trying to save non-serializable data.

```python
# Convert numpy types to Python types
results = {
    'value': float(numpy_value),  # not: numpy_value
    'count': int(numpy_count)     # not: numpy_count
}
```

### Issue: Database locked

**Solution:** Close all connections properly:

```python
# Always close connections
conn = database.connect_db()
try:
    # ... operations ...
finally:
    conn.close()
```

## 🎯 Best Practices

### 1. Always Use Try-Except

```python
try:
    database.save_result(...)
except Exception as e:
    print(f"⚠️ Warning: {e}")
    # Don't crash - database saving is optional
```

### 2. Structure Data Properly

```python
# Good - Clean, serializable
input_data = {
    'n_groups': 3,
    'n_samples': 30,
    'alpha': 0.05
}

# Bad - Non-serializable
input_data = {
    'groups': [numpy_array1, numpy_array2],  # Can't serialize
    'function': lambda x: x**2                # Can't serialize
}
```

### 3. Keep Interpretations Concise

```python
# Good - Brief summary
interpretation = "F(2, 27) = 4.56, p = .023. Significant difference found."

# Bad - Too detailed
interpretation = "The one-way ANOVA revealed... [5 paragraphs]"
```

### 4. Add Meaningful Metadata

```python
metadata = {
    'user': 'John Doe',
    'report_title': 'Q4 Performance Analysis',
    'settings': {'alpha': 0.05, 'correction': 'bonferroni'}
}
```

```python
with database.DatabaseManager("stats_app.db") as db:
```

### Batch Operations

```python

with database.DatabaseManager() as db:

        database.save_result(
            analysis_type=analysis.type,
            input_data=analysis.input,
            result=analysis.result,
            interpretation=analysis.interpretation
        )
```
